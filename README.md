# MauriOne السيارات

مشروع مستقل بالكامل لمعرض السيارات.

## العزل
هذا المستودع لا يعتمد على `maurione-web` ولا `maurione-store` ولا يستخدم Firebase أو Cloudinary الخاصين بأي مشروع سابق.

## التشغيل
```bash
npm install
npm run dev
```

## Production
أنشئ Firebase جديدًا وCloudinary إعدادًا مستقلًا، ثم أضف القيم الموجودة في `.env.example` إلى بيئة النشر.
